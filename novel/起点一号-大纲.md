# 《起点一号》（暂定名）总大纲

> 类型：三国穿越爽文｜视角：吕布（穿越者）｜体量目标：约 500 万字  
> 人设基准：《三国演义》（非正史考据向；剧情可因穿越改写，但角色性格、能力标签、关系网须贴演义）

---

## 〇、已锁定设定

| 项 | 选择 |
|----|------|
| 穿越节点 | 初平三年（192）杀董卓后、长安未破前 |
| 金手指 | **纯智变**：无系统/商城/抽将；靠现代认知 + 熟悉《演义》走向 + 吕布顶级武力 |
| 女线 | **争霸主线**：貂蝉等按演义登场，有情但不抢戏，不走后宫 |
| 终局 | **改朝换代**：一统后称帝建新朝（人物逻辑仍贴演义） |
| 主角内核 | 有家国情怀，**民为重、民生优先**；可在时间地点合适时提前收服诸葛亮、赵云等；刘备势力后期可考虑收服 |

---

## 一、一句话核心（卖点）

穿越者带着「民为贵」与全剧透支情报，降临刚诛董卓的吕布之身——以天下第一武力为刃、以关中天子为旗、以民生新政为根，先做「汉室功臣」，再在汉祚难挽时顺天受禅，扫平群雄，开万世新朝。

**爽点公式（全书通用）：**

`武力碾压（爽） + 政治先知（智爽） + 民生立威（正爽） + 打脸「三姓家奴」标签（正名爽） + 名将名士归心（收集爽，克制）`

## 二、主题与主线逻辑（必须贯穿 500 万字）

### 2.1 双主题

1. **正名**：吕布不是反复无常的武夫，而是「能杀权奸、能安百姓、能定天下」的开国之君。  
2. **民本**：武可破军，国靠仓廪与人心；每一次扩张都要回答「百姓得了什么」。

### 2.2 合法性三段论（解决「家国情怀」与「改朝换代」的矛盾）

| 阶段 | 对外旗帜 | 对内实质 | 演义逻辑支撑 |
|------|----------|----------|--------------|
| 前中期 | 诛董安汉、奉天子令诸侯 | 控兵、控粮、控人事 | 曹操「挟天子」同构，但主角更重民生 |
| 中后期 | 清君侧、讨不臣、救生民 | 汉帝暗弱、权臣环伺、州牧割据已不可逆 | 「汉德衰微」反复铺垫 |
| 终局 | 汉帝禅让 / 应天革命 | 新朝开国，制度落民生 | 曹丕受禅、刘备称帝的演义路径，主角完成「真统一」 |

> 注意：主角**真心想安民**，不是一上来就谋篡。篡位必须是「汉不可救、民不能再乱」之后的被动必然，否则人设崩。

### 2.3 反派梯度（爽文节奏）

1. **近敌**：王允党、凉州军（李傕郭汜）、长安权斗  
2. **中原敌**：袁术（称帝靶子）、陶谦/徐州变局、公孙瓒等  
3. **终极大BOSS线**：曹操（智力/组织力）、袁绍（家世/河北）、江东孙氏（后期）、其余割据填爽点  
4. **理念之敌**：刘备集团（仁德镜像）——不宜早灭，宜后期「收服/同化」，制造情感与价值观高潮

## 三、主角与金手指边界

### 3.1 穿越者能力边界（防崩）

**能用：**

- 知道《演义》大走向与关键人物性格弱点  
- 现代常识：户籍、屯田、漕运、军纪、防疫、舆论、情报组织雏形  
- 吕布本体：方天画戟、赤兔、骑战无双、威慑力拉满  

**不能用：**

- 凭空造火药枪炮、蒸汽机（可有「改良连弩/水碓/翻车」等轻科技，但不得变成科幻）  
- 先知到「精确到日」的剧本——历史已因穿越偏离，越后期预知越失效（这是中后期张力来源）  
- 一口说服所有人：名士需要政绩与名声，武将需要恩义与战场

### 3.2 主角性格（穿越后合成）

| 层 | 内容 |
|----|------|
| 表层（外人看） | 依旧「人中吕布」：果决、霸气、杀伐分明 |
| 里层（心腹知） | 重民、重诺、能忍、能分权 |
| 绝对禁忌 | 不再因酒色杀功臣；不再毫无底线跳槽；不把忠诚当消耗品 |
| 成长弧 | 从「会打仗的穿越者」→「会治国的雄主」→「能托六合的开国之君」 |

## 四、关键角色人设（严格贴《演义》标签）

> 原则：性格、能力、口头禅式标签不变；**命运可变**。收服必须给「符合其人设的理由」。

### 4.1 核心班底（早期必须稳住）

| 角色 | 演义标签 | 本书用法 |
|------|----------|----------|
| 吕布（主角） | 无敌武勇、原刚愎反复 | 武力保留，性格被穿越修正；对外仍要「像吕布」 |
| 貂蝉 | 美人计核心、与吕布情愫 | 有情有义，助内政/情报/人心，**不后宫、不抢争霸戏** |
| 王允 | 诛董功臣、迂腐不善军 | 前期盟友→障碍；架空而非简单屠刀，体现政治爽 |
| 李傕、郭汜、张济、樊稠 | 凉州狼虎 | **必须收编**，否则长安必破；收编过程是第一卷最大智斗 |
| 张辽 | 忠勇善战、可属明主 | 早期心腹武将，长期「吕营第一上将」候选 |
| 高顺 | 陷阵营、清廉刚正 | 绝对留用；军纪样板 |
| 陈宫 | 多谋、理想高、易失望 | 民生新政的重要推手；主角必须用「政绩+信任」锁死忠诚 |
| 陈登等 | 地方名士 | 徐州/江淮线再引入 |

### 4.2 可提前收服（时间地点合适才收）

| 角色 | 最早合理窗口 | 收服逻辑（贴人设） | 不合适应放弃 |
|------|--------------|-------------------|--------------|
| **赵云** | 公孙瓒尚在 / 河北动荡期 | 赵云「不事暗主」、重义；主角以救民实绩+光明磊落招之 | 若强扭在徐州乱局硬抢，易显降智 |
| **诸葛亮** | 隆中未出前（约建安前后） | 亮择主看「能成大事+顺民心」；主角需已有稳土、有制度、有「可辅之君」气象 | 长安草创期去南阳硬挖＝违和；可先埋线「三顾/临局访贤」变体 |
| 黄忠、魏延等 | 南征/荆襄线 | 按演义本事场登场再收 | 不提前空降 |
| 太史慈、甘宁等 | 江淮/江东线 | 武勇相惜或明主吸引 | 同左 |

### 4.3 刘备势力（后期收服专项）

| 角色 | 演义标签 | 收服策略 |
|------|----------|----------|
| 刘备 | 仁德、枭雄底色、哭与结纳 | 不宜早杀；长期「竞合」：共同打曹/袁，比民生、比人心；末期以「天下已定、生民为重」迫其抉择——降、禅、或保爵归朝 |
| 关羽 | 忠义压倒一切 | 最难收；必须满足「义」：或刘备亲口相托，或汉帝/新朝大义框架下的「全兄之志」 |
| 张飞 | 猛而敬君子 | 随刘备线；敬重主角「安民不屠城」可感化 |
| 诸葛亮（若已在备营） | 鞠躬尽瘁 | 若备营已得亮，则走「主公选择」戏，不可强抢无代价 |
| 庞统、法正等 | 奇谋、功利 | 可用「定乱」吸引，较关羽好收 |

**收服刘备集团的总原则：**  
不是「打服」，而是「比刘备更救得了天下百姓，又给足刘备仁义台阶」。否则关羽线必崩。

### 4.4 宿敌与镜像

| 角色 | 功能 |
|------|------|
| 曹操 | 终极对手：一样挟天子、一样会用人；主角胜在**更早窗口+民本真干+不养祸** |
| 袁绍 | 色厉内荏、外宽内忌；河北大战的「名门靶子」 |
| 袁术 | 称帝送人头，前期打脸素材 |
| 孙权 | 后期江东险地，水战逼主角补短板 |
| 司马懿（可选后段） | 若一统偏长，作权臣隐患或二代铺垫；500万字可收在开国，不必硬写三代 |

### 4.5 女线（克制）

- **貂蝉**：唯一重点感情线。从「美人计余波」到「君臣夫妻式信任」。可参与宫变情报、安置难民、稳定关中人心。  
- **严氏**：按演义可保留家庭张力，不扩展后宫。  
- 其余演义女性角色：按原著功能出场，不收集。

## 六、分卷细纲

### 第一卷｜长安棋局（约 45 万字）

**开篇钩子：**  
穿越落地＝董卓已死、长安沸腾。主角第一夜就要决定：杀李傕还是赦李傕。

**主线节拍：**

1. **三日求生**：清宫变、稳禁军、见献帝、定「诛董功臣」叙事。  
2. **凉州赦免令**：违王允，遣使授官、分地、质家、给粮；张辽、徐荣等站队戏。  
3. **王允之困**：朝堂舌战——迂腐理想 vs 救民现实；架空王允，留其「诛董清誉」作牌坊。  
4. **李傕试忠**：必有一场「半叛乱」供主角武杀+智收；高顺陷阵营首秀。  
5. **貂蝉去留**：谣言、士族耻笑、旧情；主角以「不弃、不纵、不乱政」定调。  
6. **卷末**：关中粗定，东方传来曹操破黄巾/收兖州情报——主角决定「先固本，再东向」。

**逻辑红线：** 此卷若放任凉州军溃散＝重演演义崩盘，全书开局失败。

**卷末钩子：** 第一道屯田令与「盗贼安民诏」。

---

### 第二卷｜关中新政（约 45 万字）

**核心矛盾：** 武夫能不能治国？士族嘲讽「吕布只配执戟」。

**主线节拍：**

1. 清丈、屯田、减赋、军纪三章（高顺执法，陈宫制度）。  
2. 打击关中豪强隐户（打虎爽，但要防「官逼民反」）。  
3. 重建西园/典军体系，赤兔营、陷阵营、凉州骑分工。  
4. 外交：拉拢袁绍（远交）、压制袁术、观察曹操。  
5. 小规模外战（郭汜旧部反复、边章余党、羌乱）证明新政能打仗。  
6. **埋线**：探听刘备动向、公孙瓒部下赵云之名；南阳诸葛尚隐。

**民生戏占比升高**——这是主角区别于演义吕布、也区别于曹操的「招牌」。

**卷末：** 献帝东迁之议起（主动护送东出，而非被李傕逼走）。

---

### 第三卷｜虎出函谷（约 50 万字）

**核心任务：** 把「关中王」变成「中央」。

**主线节拍：**

1. 奉帝出关，粮道与舆论战（「吕布劫迁」谣言 vs 「恭迎车驾」实绩）。  
2. 洛阳残破：重建太仓、安集流民——仁名扩散。  
3. 袁术称仲家前的嚣张：打脸战（可提前激袁术称帝，造「天下共讨」）。  
4. 与曹操第一次间接碰撞：兖豫交界抢人才、抢粮心。  
5. 名场面：主角亲骑突击，演义级「单骑俱敌」但服务于战役目标，不浪。

**卷末：** 曹操意识到「吕布非吴下阿蒙」，开始全面布局。

---

### 第四卷｜兖豫风云（约 55 万字）

**定位：** 第一次「主角团 vs 曹营」全面战争。

**主线节拍：**

1. 陈宫系谋略 vs 荀彧荀攸（智斗，主角不降智）。  
2. 濮阳、钜野及官渡前序战改写：目标不是浪漫决斗，是**断曹操的人口与屯田**。  
3. 挖墙脚：戏志才早逝窗口、郭嘉是否可争（难，但可写「差一点」增加恨意）。  
4. 曹操最危险时主角选择：**可灭而不屠城、可杀而留降**，埋「得人心」与「养虎」双刃——最终以制度监控降将，不学宋襄。  
5. 张辽前线成长；许褚/典韦级名场面对撞。

**卷末结果建议：** 曹操退保一隅或元气大伤，但未死——留给后卷；主角得兖豫大部。

---

### 第五卷｜徐州归心（约 50 万字）

**定位：** 仁名建国关键卷；刘备正式成为镜像。

**主线节拍：**

1. 陶谦病重/徐州无主：主角以「不屠、减赋、严军」入徐（对比演义曹屠徐州）。  
2. 刘备入徐援助或牧徐：二人「并肩」一场，再分道——竞合开始。  
3. 陈登父子、糜竺等归边；貂蝉线以「安民见真章」升温但不喧宾。  
4. 吕布原剧「夺徐叛备」剧本被彻底改写：主角要的是**盟或收**，不是背刺。  
5. 小沛/下邳名场面重写：可打可和，关键是「信」。

**卷末：** 曹操卷土重来或袁术崩盘；刘备走依他镇，留下「羽德未竟」钩子。

---

### 第六卷｜河北雷霆（约 55 万字）

**定位：** 灭袁绍级大战；**赵云归心**。

**主线节拍：**

1. 公孙瓒覆灭前后：赵云无处托身——主角以「不屠易京余民+光明诏书」召之。  
2. 赵云测试：一场护民撤退/护粮，主角亲自断后（武力爽+义爽）。  
3. 官渡结构变奏：主角居「中央+兖豫+关中」压河北；曹操或成侧翼、或成暂时同盟打袁。  
4. 袁绍败亡：田丰、沮授命运可改写为「降而复用」或「死谏成仁」，增强厚重。  
5. 河北定，天下半。

**赵云收服完成标准：** 赵云自己说「云得明主」，而非简单「被打服」。

---

### 第七卷｜南阳卧龙（约 50 万字）

**定位：** **诸葛亮线**；智囊天花板归位。

**时间地点条件（满足才收）：**

- 主角已有稳固大盘与民生政绩  
- 刘表病势/荆州危局出现  
- 诸葛亮尚可择主（刘备未成绝对羁绊，或备亮未深）

**主线节拍：**

1. 打听「卧龙凤雏」；陈宫/新谋士引出。  
2. 访贤不落俗套：不是简单照抄三顾，而是「先看其安民策，再请其出山」——诸葛亮考的是君，不是亭。  
3. 隆中对变奏：目标从「三分」改为「先荆襄、后巴蜀、终一统」的**统一路线图**。  
4. 取荆：外交+军事；刘琦刘琮线；曹操南下压力。  
5. 庞统、徐庶等可平行收；徐庶「母」局可改写为情报战胜利。

**若刘备已得诸葛亮：** 本卷改为「亮在备营，主角以大势逼备合作」，收服推迟到第九卷。

### 第八卷｜赤壁变奏（约 55 万字）

**定位：** 打破「火烧赤壁→三国」宿命；补水军短板。

**主线节拍：**

1. 水军从零到有：用淮南船工、青徐水手、诸葛亮/庞统策划。  
2. 周瑜、鲁肃、孙权的江东博弈：可战可联，但必须削弱「南北对峙」永久化。  
3. 曹操若南征：赤壁不是主角被烧，而是主角**改写火攻归属/提前破连环**。  
4. 江东要么称臣、要么缩岛——留下统一后患清理到第十卷前。  

**卷末：** 南方门户打开；刘备若据蜀，则进入「最后的仁德之地」。

### 第九卷｜蜀道与终局战（约 50 万字）

**定位：** 刘备集团收服；全书最难的「义理题」。

**主线节拍：**

1. 汉中争夺：张飞、黄忠名场面保留风味，胜负可改。  
2. 主角与刘备终极谈判：天下战乱年数、户口减半、再战则民尽。  
3. **关羽线**：必须单开高潮——战或盟都要给足「义」；建议结局之一：「刘备托孤式托弟」——备病/禅位爵，羽以「兄命+安民」归朝，永不降格成滑稽反水。  
4. 诸葛亮若在备侧：亮劝备「民为重」，完成理念胜利。  
5. 残余：南中、辽东公孙、羌胡——快刀收束。

### 第十卷｜应天开国（约 45 万字）

**定位：** 禅让、制度、收束人物。

**主线节拍：**

1. 汉帝诏禅（铺垫十卷）：主角三辞三受（演义礼仪感）。  
2. 国号、都城、年号；关中/洛阳象征意义。  
3. 开国国策：均田/屯田制度化、军户与民户、科举雏形或察举改良——点到为止，服务「民生主题」。  
4. 功臣表：张辽、高顺、赵云、诸葛亮、陈宫、旧凉州降将各有归宿。  
5. 貂蝉：皇后或贵人定位克制，强调「共经患难」，不写后宫斗。  
6. 终章：边烽已息，麦熟，主角微服见民——呼应开篇「民为重」。

## 七、500 万字防注水与爽点节奏

### 7.1 每 10 万字至少一个「记忆点」

- 武戏记忆点：单骑、陷阵、隔岸射戟变奏、与典韦许褚对撞等  
- 文戏记忆点：朝会打脸、名士投效、民生诏令见效  
- 情义记忆点：貂蝉、赵云、关羽、陈宫危机

### 7.2 每卷固定三板斧

1. 开卷危机（要亡/要乱）  
2. 中卷翻盘（智或武）  
3. 卷末升维（地盘/人才/名望三选二以上）

### 7.3 严禁的注水

- 重复「下战书—单挑—对方傻站」超过功能需要  
- 无意义后宫与无意义酒宴  
- 预知剧情复读（中后期预知失效，改为情报战）

## 十、叙事与文风建议（方便开书）

- **人称**：第三人称限知为主，主角偶尔内心独白（穿越感）。  
- **对白**：偏白话演义风，忌过度网文梗刷屏；可用少量现代思维内心戏。  
- **章末钩子**：危机/反转/名将现身/民生捷报轮换。  
- **标题风格**：可偏传统（「吕奉先长安定策」「赵子龙归心」）或偏网文，全书统一即可。

## 十一、开书前仍可微调的「非骨架」项

下列不影响已锁骨架，开写前可再定：

1. 书名、国号、年号  
2. 都城最终定关中还是洛阳  
3. 曹操结局：俘/杀/废/病死  
4. 刘备结局：王爵善终 / 出家式退隐 / 病逝托弟  
5. 单章字数与更新节奏（影响分章，不影响卷纲）

## 十二、结论（大纲压缩版）

- **起点**：192 年长安，诛董后唯一「大义+天子+董卓遗产」窗口。  
- **手段**：纯智变 + 吕布武力；先收凉州、固关中、民生立国，再东向。  
- **对手**：曹操为组织力之敌，刘备为道德镜像之敌，袁绍袁术为阶段靶子。  
- **人才**：赵云在河北窗口收；诸葛亮在荆襄窗口收；刘备集团终局以「民」与「义」收。  
- **感情**：貂蝉克制陪伴，不后宫。  
- **终点**：汉祚难挽后应天禅让，称帝一统，民生制度落地。

## 附录 B｜主角决策检查清单（每卷自检）

1. 此决策是否让百姓少死人、多活口？  
2. 是否还在「汉臣」叙事能解释的范围内？（中后期可松）
