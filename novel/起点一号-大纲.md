# 第一块：总纲领与红线

## 1.1 一句话核心（卖点）

穿越者夺舍刚诛董卓的吕布，无系统、靠《演义》先知与现代权谋，把「天下无双的武力」补上「帝王格局」与「民本之心」，从长安起步，经长期与曹、刘、孙博弈，最终灭群雄、称帝建新朝。

## 1.2 爽点公式（贯穿 500 万字）

```
武力碾压开路 → 政治阳谋打脸 → 民生立威正名 → 收服演义名将名士 → 对手按原人设反制 → 我方更高一筹反杀
```

爽要密，但不能靠降智：曹操仍奸雄，孔明仍神算，关羽仍傲义——你赢，是因为棋差一招被你算穿，不是他们突然变蠢。

## 1.3 主角规则

| 层 | 内容 |
|----|------|
| 身体 | 吕布原武力、原声望、原班底（高顺、张辽等按演义逐步到位） |
| 灵魂 | 现代人，熟《演义》主线，无外挂；有家国情怀，民为重 |
| 对外 | 仍是「温侯」，但决策一反原著脑残 |
| 对内 | 可写短暂身份认同冲突，不抢主线 |
| 女线 | 貂蝉等按演义出场，有戏但不扩张后宫、不喧宾夺主 |
| 绝对禁忌 | 不再因酒色杀功臣；不再毫无底线跳槽；不把忠诚当消耗品；不以屠城虐民堆爽 |

## 1.4 《演义》人设红线（全书必须守）

- **曹操**：奸雄，有真本事，能用人、能忍、能诈  
- **刘备**：仁义牌面 + 枭雄底色，善于笼络人心  
- **孙权**：守江东、能权变，不是背景板  
- **诸葛亮**：未出山前藏锋，出山后是顶级对手/智囊，不可被轻易碾成炮灰  
- **关张赵等**：忠义勇烈按原著脾气行事  
- **陈宫、王允、李傕郭汜**：按原性格推动剧情，用智谋收编/制衡，而不是作者开挂抹掉  

## 1.5 合法性三段论（家国情怀 × 称帝终局）

| 阶段 | 对外旗帜 | 对内实质 |
|------|----------|----------|
| 前中期 | 诛董安汉、奉天子令诸侯 | 控兵、控粮、控人事；真心安民 |
| 中后期 | 清君侧、讨不臣、救生民 | 汉祚衰微已不可逆，铺垫充分 |
| 终局 | 应天革命 / 受禅称帝 | 新朝开国，制度落民生 |

> 主角**真心想安民**，不是一上来就谋篡。称帝必须是「汉不可救、民不能再乱」之后的被动必然。

## 1.6 金手指边界（防崩）

**能用：**《演义》大走向与人物性格弱点；现代常识（户籍、屯田、漕运、军纪、防疫、情报组织雏形）；吕布骑战无双。  

**不能用：**凭空造枪炮蒸汽机（轻改良可有，不变科幻）；精确到日的剧本（越后期预知越失效）；一口说服所有人。

## 1.7 收服逻辑总表

| 角色 | 可收服条件（演义向） | 不宜强行 |
|------|----------------------|----------|
| 赵云 | 见主公不屠民、赏罚信、可托付百姓 | 尚未立德就靠官爵砸 |
| 诸葛亮 | 见长期安民路径 + 可尽其才的君臣关系 | 吕布还在反复横跳/草创未稳时去三顾 |
| 刘备势力 | 后期势穷，或见你更能安民且给宗室/百姓出路 | 前期强吞，写成刘备无脑献江山 |
| 关羽 | 需「义」与「民」说得通，或旧主托孤 | 无视傲气直接劝降成功 |

# 第二块：十分卷总纲（约 10×50 万 ≈ 500 万）

> 对手线按锁定项 **A. 长期三足对峙**：中期必须形成「关中/中原吕 — 北方曹 — 荆蜀刘 — 江东孙」多极博弈，再逐一击破。  
> 估算：约 1000～1200 章，均章 4000～5000 字。

### 卷一｜长安定鼎（约 50 万）★本章纲已展开，见第三块

**时间**：诛董之后数月。  
**主线**：否决王允尽诛凉州人；赦李傕、郭汜而分其权；架空清流空谈，握住兵符与粮权；稳定三辅民生。  
**爽点**：凉州军以为必反，反被「赦罪授官 + 以法绳之」；朝臣笑吕布无脑，反被军政两手打脸。  
**收官**：关中初安，天子尚在掌握，天下始知「温侯能治国，非一介武夫」。

### 卷二｜西凉归心·东出序章（约 50 万）

**主线**：经营凉州骑兵与关中农桑；打通陈仓/武关；第一次东出试探。  
**人物**：贾诩按演义多智——或收、或制衡；布局兖豫情报网（先知用于提前布局，不是开天眼秒杀）。  
**民生**：屯田雏形、安置流民，为「王道招牌」打底。  
**收官**：关中成铁桶，具备争中原资格。

### 卷三｜兖豫争锋（约 50 万）

**主线**：与曹操正面碰撞（曹操仍是能吏奸雄）；陈宫线按演义智谋争取或交锋。  
**爽点**：战场武力碾压；庙堂用民生与盟约拆曹操「奉迎天子」道义牌（或抢先奉迎，逻辑自洽即可）。  
**收官**：中原形成「关中吕 vs 兖豫曹」双强；**不灭曹操**，保留长期对手。刘备尚弱、江东未大。

### 卷四｜河北风向·子龙可期（约 50 万）

**主线**：介入公孙瓒/袁绍格局。  
**赵云**：在公孙瓒处或流浪节点，用「不扰民、赏罚明、可托孤百姓」打动——符合演义子龙忠义、爱民、择主而事；时机不对则只结善缘。  
**爽点**：河北名将试锋；温侯「神威」打服骄兵，对百姓秋毫无犯，名声两极反差。  
**收官**：赵云归心（或深度结缘）；河北局势搅动，曹袁吕三角更复杂。

### 卷五｜荆襄暗线·卧龙择主（约 50 万）

**主线**：经略南阳/荆北边缘，声誉传到隆中。  
**诸葛亮**：不硬抢。以「安民实绩 + 结束乱世的路径 + 君臣相知」请见；若刘备已成气候，则改为三方博弈中的挖角/同盟。  
**收官**：要么孔明入幕，要么孔明入刘营但埋下「日后可转」的民生价值观线索。

### 卷六｜三足初成（约 50 万）

**主线**：曹操称霸北方一极，孙权坐稳江东，刘备取势荆/徐之一角；主角控关中+部分中原，**天下三分（或四分）定型**——兑现「长期三足」锁定。  
**爽点**：会盟与背刺皆按演义性格推演——曹诈、刘仁中藏枭、孙权衡。  
**人物**：张辽、高顺、徐晃等按原人设归心或交锋。

### 卷七｜火烧与水淹的「改写权」（约 50 万）

**主线**：经典大战（官渡类、赤壁类、合肥类）在蝴蝶效应下重演，因果合理：情报、粮道、民生、人心，而非背答案作弊。  
**原则**：大事件可改结果，人物决策动机必须仍是原人设。  
**收官**：曹操受重创但不崩；孙权自保；刘备或强或危，为后文收服留口。**三足仍在，进入收束期。**

### 卷八｜伐曹主旋律（约 50 万）

**主线**：集中打垮曹操势力；许昌/邺城级决战；招降曹营能吏名将（按性格给出路，不降智）。  
**民生**：新占区先「救民于水火」，再谈州郡官制。  
**收官**：北方大局定，曹氏或灭或降为藩——**三足拆一**。

### 卷九｜江东与刘备收官（约 50 万）

**主线**：对孙权——战与和并用，水军短板用时间补，不幻想陆战秒灭江东。  
**刘备线**：若刘备穷途，用「百姓安、汉祀不绝/宗室优待、君臣名分可全」谈判收服；关羽傲、张飞暴、孔明忠——能收则收，不能收则悲壮对决，不强行团宠。  
**赵云/孔明**：若前卷未入，本卷给最终归宿。  
**收官**：**三足拆尽**，只余清盘。

### 卷十｜混一天下·称帝建新朝（约 50 万）

**主线**：最后割据清盘；受禅或武力定鼎后称帝；定国号、定都、定税制、定军制；功臣册封；演义遗留人物结局。  
**爽点终章**：昔日笑吕布「无谋」者跪迎新帝；收束落在「四海初安、劝课农桑」。  
**终局**：新朝立，乱世终。

# 第三块：卷一细纲（章纲级）

> 卷一目标约 50 万字 ≈ **100～120 章**（均章约 4～5 千字）。

## 3.1 卷一总目标与红线

| 项 | 内容 |
|----|------|
| 时间 | 初平三年春夏，诛董后约数月 |
| 必须做成 | 凉州军收编成功；长安不破；兵符粮权在手；民生新政起步；「能治国」声名初立 |
| 绝对禁止 | 放任王允尽诛凉州人；无脑屠长安；开局就称帝；系统外挂 |
| 卷末状态 | 关中粗定；东方曹操破黄巾/收兖州情报抵达；主角决意「先固本，再东向」 |
| 卷末钩子 | 第一道屯田令生效 + 兖州变局的探马急报 |

## 3.2 开篇 30 章章纲（爽点节奏已标）

### 第一幕：落地三昼夜（第 1～8 章）——求生 + 立旗

**第1章｜画戟未冷**  
董卓已死，未央火未熄。穿越者在吕布躯壳中醒来：血、戟、朝臣欢呼、李傕郭汜尚在城外营中。第一反应不是得意，而是：**长安破城的演义结局倒计时已开始**。  
**爽点**：身份确认 + 死亡倒计时压迫感（开书钩）。

**第2章｜王允的刀**  
王允以「诛贼余党」为由，欲尽灭凉州人在京者。朝堂一片附和。主角以内心《演义》记忆对上王允面容——知此为亡国之策。当众暂压屠刀：「先清宫禁，再议赏罚。」  
**爽点**：第一句「否决」——众人愕然：吕布也会救人？

**第3章｜见帝**  
入见献帝。不演莽夫，行人臣礼，请下「安民赦书」草稿权限。献帝怯而喜。宦官士族各怀鬼胎。  
**人设**：对外仍是功臣温侯，对内已是「借天子令」的现代权谋者。

**第4章｜兵符与粮**  
连夜清点北军、羽林、董卓府库。发现王允只控名义、兵心散乱、粮在西凉旧将之手。主角命高顺闭城门、张辽巡街，自己亲自点兵——**武力威慑落地**。  
**爽点**：一人压住哗变边缘的乱兵（小武戏）。

**第5章｜貂蝉一问**  
貂蝉按演义人设：惊、疑、情。士族已有「妖女乱政」流言。主角定调三句：**不弃、不纵、不乱政**。托她安抚董府旧人女眷、探听里巷民情——感情线有，但不抢戏。  
**爽点**：打脸「重色无谋」预期。

**第6章｜陈情书**  
主角口述、文吏笔录：上《安凉州疏》——赦罪、授官、分屯、质家、给粮，五条并进。王允怒斥「养虎」。主角反问：「虎在城外，杀城内老弱，虎怒则长安为肉。」  
**爽点**：朝堂第一场阳谋打脸（文戏高潮）。

**第7章｜死士夜出**  
遣使出城见李傕、郭汜：使者不是文弱书生，而是主角点出的「凉州能说话的人」+ 张辽陪同（演义张辽智勇，适合作桥）。密信内容：官职、驻地、粮数写死，另附「三日不报，温侯自来」。  
**爽点**：不是跪求，是**带刀的和解**。

**第8章｜三日之约**  
城内清流骂「软弱」；城外凉州军内讧（李傕疑、郭汜暴、贾诩尚未明牌）。主角在城头练兵，赤兔一骑震慑流言。  
**幕收**：探马回报——凉州营中有人愿谈，有人愿战。  
**爽点**：危机未解，但主动权已从「等死」变成「双向选择」。

### 第二幕：凉州棋（第 9～18 章）——收编为本卷最大智斗

**第9章｜贾诩之眼**  
按演义：贾诩多智。他看出「尽诛」是死、硬战也可能死，唯「受赦而分权」可活。贾诩劝李傕「且听温侯条件，再观其诚」。  
**人设**：贾诩不是秒投，是**自保型智者**在算概率。

**第10章｜营门会**  
主角亲赴凉州大营（可带陷阵营精锐为后盾）。李傕试探、郭汜叫骂。主角不跪不傲：先亮赦书，再亮粮单，最后一句话——「反则我先斩尔祭旗，降则昨日种种一笔勾销。」  
**爽点**：武力威压 + 条件清晰的阳谋（本卷名场面之一）。

**第11章｜分而治之**  
授官方案落地：李傕、郭汜、樊稠、张济各有驻地与粮道，**互不统属**，皆须向长安「报民户、报马匹」。质家入京（优待而非虐）。  
**逻辑**：收编成功的关键不是「信任」，是**结构上让他们抱不成团破长安**。

**第12章｜半叛之战**  
必有一支不满的凉州偏将（或郭汜部曲）劫粮试火。主角不屠营，只灭首恶：高顺陷阵营首秀，主角画戟斩将。  
**爽点**：武戏爆发；收编不是无代价和平。

**第13章｜以法绳之**  
战后颁布《军中约法》：劫民者斩、匿户者笞、妄议复反者流。凉州兵第一次发现——温侯真给粮，也真杀人。  
**民生**：长安里巷流民第一次吃到「官赈」。  
**爽点**：正爽（军纪）+ 民心初动。

**第14章｜王允反扑**  
王允联合朝中清流，劾主角「私授贼帅」「闭塞言路」。献帝摇摆。主角请「廷议」：把凉州军昨日劫民证据与今日安民条陈并陈。  
**爽点**：二次朝堂打脸——用**事实**压迂腐。

**第15章｜架空而不屠刀**  
削王允兵权与选官实权，留其「诛董功臣」名号与司徒虚位——当牌坊，不当指挥官。部分死硬党外放。  
**人设**：王允仍是理想主义忠臣，不是小丑；他恨，但百姓暂安。  
**爽点**：政治老辣，异于演义吕布。

**第16章｜张辽拜心**  
张辽在收编与执法中确认：此主可辅。夜谈：主角许以「不扰民、赏罚信」。张辽请为先锋。  
**收集爽（克制）**：第一员核心心腹武将真正归心。

**第17章｜高顺之镜**  
高顺清廉刚正，质疑「赦贼」。主角带他微服看难民营——「不赦，明日这些人都是鬼。」高顺沉吟，请扩陷阵营、严选士。  
**人设**：高顺不是愚忠，是**被「民」说服**。

**第18章｜长安不破**  
贾诩入见（或远程上策）：献「缓兵安民、徐图东方」。主角不立刻委以全权，先用其策、观其心——符合演义贾诩反复/自保标签。  
**幕收**：城外营寨改「屯」，长安城门开昼市。  
**本卷第一个大闭环完成：历史崩盘点被改写。**

---

### 第三幕：温侯能治国？（第 19～30 章）——民生立威 + 正名

**第19章｜三辅疮痍**  
视角下沉：豪强隐户、盗贼横行、麦田荒芜。穿越者召开第一次「治民会议」——陈列问题，不空喊忠义。  
**主题落地**：家国情怀不是口号，是粮册。

**第20章｜陈宫至（或书至）**  
若时空上陈宫尚在曹操处：本章写主角遣使、修书，以「屯田安民」相招，留钩子到卷三；若可提前相遇，则陈宫来观政。  
**原则**：不合适不强扭。书信亦可：陈宫心折其「民」字，但未即至。  
**智爽**：先知用于布局，不是瞬间挖角成功。

**第21章｜减赋令**  
颁布关中减赋、免本年欠租（有条件：登记户籍者）。豪强反弹。主角抓典型——不抄全家，断其隐户、充公田予流民。  
**爽点**：打虎，但有法度（区别于董卓式抄家）。

**第22章｜士族的笑**  
名士酒宴嘲「执戟儿谈治国」。主角不怒，次日请其巡仓、巡营、巡难民营——笑者无言。  
**爽点**：经典打脸，服务于「正名」。

**第23章｜貂蝉与里巷**  
貂蝉协助安置女眷、幼童，传出「温侯家法不扰民」。流言从「祸水」转向复杂。主角与貂蝉一场克制夜谈：乱世里情可有，政不可乱。  
**感情线**：升温一格，仍不抢主线。

**第24章｜盗贼安民诏**  
对关中盗贼：自首编户者赦，拒者由高顺清剿。清剿战写一场短平快——武力碾压山贼，收降壮丁屯田。  
**爽点**：武戏小高潮 + 民生闭环。

**第25章｜东方探马**  
首次接到明确情报：曹操在兖州收黄巾、行屯田之议。主角心中警铃——**未来最大组织型对手已在养成**。下令：兖豫情报网启动（买商旅、养细作），不急着出关。  
**逻辑**：长期三足的伏笔——先承认曹操会成气候。

**第26章｜袁绍来书**  
袁绍以盟主余威来书试探。主角回书谦而硬：尊汉、安民、各守，暗示「凉州已定，关中非无人」。  
**人设**：袁绍外宽内忌，开始忌「吕布非武夫」。

**第27章｜献帝夜问**  
献帝问：「卿欲何为？」主角答：「先使三辅无饿死，再使山东无专杀。」不提篡，不提王。帝安。  
**主题**：合法性前段——真汉臣姿态。

**第28章｜阅兵长乐**  
长安城外大阅兵：陷阵、凉州骑、北军混编。李傕等按班侍立——**昨日之贼，今日之将**，朝野震撼。  
**爽点**：场面爽 + 「收编成功」可视化。

**第29章｜第一道屯田令**  
正式颁布屯田：军屯民屯并行，以高顺营为样板，以府库种子为本。文吏笑其「抄曹操」——主角不辩，只要求「秋后看仓」。  
**智爽**：预知变政绩竞赛，不是抄答案炫耀。

**第30章｜卷一门楣（开篇30章收束）**  
秋雨。仓廪初有存粮。里巷有孩童喊「温侯」。王允病酒，贾诩观棋，貂蝉添衣，张辽请令东巡。  
探马急报：兖州有变，曹操几危（或黄巾势大）——东方已起。  
主角立于城头，画戟在侧，一句收束开篇：

> 「长安既定。下一步，函谷以东。」

**开篇30章爽点密度小结：**

| 章段 | 主爽类型 |
|------|----------|
| 1～8 | 危机逆转、朝堂否决、立旗 |
| 9～18 | 智斗收编、武戏斩叛、政治架空 |
| 19～30 | 民生打脸、正名、情报伏笔、阅兵场面 |

## 3.3 卷一其余章节拍（第 31～120 章）

> 开篇 30 章已完成「长安不破」主闭环。后 70～90 章把「初安」升级为「可东出的关中」，并埋卷二钩子。

### 第四幕：关中深耕（约第 31～55 章）

1. 清丈田亩、打击隐户的连续拉锯（豪强反扑 → 依法再打 → 名士分化）。  
2. 重建工匠署：甲仗、马政、粮仓防水防火（轻制度，不科幻）。  
3. 凉州诸将的「不服再试」：再给一场小叛或仇杀案，用律法而非屠营解决。  
4. 贾诩地位明确化：首席「鬼谋」顾问，但被陈式制衡（分权）。  
5. 貂蝉线：一次宫变流言危机，她以情报助主角化解，感情再升温一格。  

**阶段爽点**：治国连续打脸；「武夫」标签开始在关中破产。

### 第五幕：西陲与武关（约第 56～80 章）

1. 小规模羌乱/边患：主角或张辽出征，骑兵体系成型。  
2. 打通陈仓、武关商道，商旅复业——税入可见。  
3. 第一次对外「有限战争」（对张济部摩擦或对袁术边境）：展示「能战也能停」。  
4. 人才：关中、凉州、故董府吏士归心名单拉长；可引入早期降将。  
5. 埋线：打听公孙瓒部下赵云；南阳「卧龙」仅作市井传言一笔。  

**阶段爽点**：野战无敌但不浪；民生财政数字第一次让朝臣闭嘴。

### 第六幕：东望与卷末（约第 81～120 章）

1. 兖豫情报网出成果：曹操用人、屯田、破黄巾细节到来。  
2. 朝议「东出」：主战清流 vs 主守武将；主角定策——**再稳一季，屯田见效再出**（显示能忍，异于旧吕布）。  
3. 王允线收束：病逝或致仕，留给历史「诛董」美名；主角公开祭之——政治厚道。  
4. 献帝下诏褒「安关中功」——合法性再加一砖。  
5. **卷终章**：屯田秋获；函谷以东烽烟；主角祭旗，宣告卷二序章——西凉归心已成，东出在即。  

**卷一最终验收清单：**

- [ ] 长安未破，凉州军在建制内  
- [ ] 兵符、粮权、人事权实质在主角手  
- [ ] 民生有可见成果（赈济/减赋/屯田）  
- [ ] 张辽、高顺核心班底稳固；贾诩可用  
- [ ] 曹操线已起，但不决战  
- [ ] 貂蝉有戏不抢戏  
- [ ] 无系统、无降智、无人设崩坏
